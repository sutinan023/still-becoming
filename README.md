## Deploy to GitHub Pages
- วาง `index.html` และ `resume.html` ที่ root ของ repository
- เปิด Settings → Pages → Deploy from a branch → main / (root)
- เปิดเว็บไซต์ที่ `https://sutinan023.github.io/still-becoming/`
