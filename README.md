## Design rationale

- โครงสร้าง Resume ชัดเจน ตามเวลา เน้นผลงานและทักษะ ไม่ใช้ skill bars
- HTML Portfolio เน้นความอ่านง่าย ฟอนต์ไทยเป็นระบบ เว้น whitespace และมี contrast
- `resume.html` เน้น single-column, no photos/charts, printer-friendly เพื่อช่วยลดปัญหาการอ่านของ ATS (ไม่รับประกันความเข้ากันได้กับทุก ATS)
